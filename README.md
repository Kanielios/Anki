# AnkiClone

Небольшое веб-приложение для интервального повторения карточек: колоды, импорт/экспорт CSV, обучение с оценками, статистика активности и AI-помощник через Groq.

## Возможности

- Регистрация и вход пользователей.
- Колоды с дневными лимитами новых карточек и повторений.
- Карточки с тегами, быстрым редактированием и поиском.
- Учебный режим с переворотом карточки, горячими клавишами `1`-`4`, подсказками следующих интервалов и отменой последнего ответа.
- Импорт и экспорт CSV в формате `front,back,tags`.
- AI-генерация обратной стороны карточки, если настроен `GROQ_API_KEY`.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

После запуска открой:

```text
http://127.0.0.1:5001
```

## Переменные окружения

- `SECRET_KEY` — секрет Flask-сессий. Для локальной разработки можно сгенерировать любой длинный случайный текст.
- `GROQ_API_KEY` — опциональный ключ Groq для AI-функций.

## GitHub

В репозиторий стоит коммитить код, шаблоны, `requirements.txt`, `README.md` и `.env.example`.

Не стоит коммитить:

- `.env`
- `*.db`
- `venv/` или `.venv/`
- `__pycache__/`
